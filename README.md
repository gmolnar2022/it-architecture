# IT Architecture – Quarto course project

The project contains all six completed English lectures:

- Lecture 01 – Hardware Fundamentals I
- Lecture 02 – Hardware Fundamentals II
- Lecture 03 – Operating Systems: Introduction
- Lecture 04 – Operating Systems: Process Scheduling
- Lecture 05 – Operating Systems: Resource Management and I/O Scheduling
- Lecture 06 – Operating Systems: Memory Management

All lectures use the same uniform full-canvas PowerPoint-to-Reveal.js approach. Each PowerPoint slide is rendered as a full-slide image, while extracted slide text is stored in Reveal.js speaker notes.
