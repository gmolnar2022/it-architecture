CPU Socket

The CPU socket provides the connection between the processor and the motherboard.

Main socket types LGA = Land Grid Array PGA = Pin Grid Array BGA = Ball Grid Array

LGA Socket

Characteristics The pins are located in the socket They connect to the contacts on the underside of the CPU

Reduces processor manufacturing cost Stable electrical connection Examples: LGA 775 (2004), LGA 1156 (2009), LGA 1155 (2011), LGA 1150 (2013), LGA 1151 (2015), LGA 1200 (2020), LGA 1700 (2021), LGA 1851 (late 2025?)

Primarily used by Intel processors

PGA Socket

Characteristics The pins are located on the processor They connect to the holes in the socket

Requires more space Less durable Easier CPU installation Examples: Socket A (2000), Socket AM2 (2006), Socket AM3 (2009), Socket AM1 (2014), Socket AM4 (2016)

Today, AMD also uses LGA sockets, e.g. Socket AM5 (2022)

Primarily used by AMD processors

BGA Socket

Characteristics Small solder balls instead of pins The processor is fixed in place (soldered connection) Compact size Not replaceable Other components can also be integrated alongside the CPU

Examples: BGA 437 (2009), BGA 956 (2013), BGA 1526 (2018), BGA 1787 (2021), BGA 2114 (2022), BGA (2540) ?

Primarily used in laptops and mobile devices

Intel Processors – 16-bit

The 8086 launched the x86 era, while the 8088 powered the first IBM PC.

ARM Processor Architecture

64-bit RISC architecture Manufacturers: Apple, Qualcomm, MediaTek, Ampere, AWS Heterogeneous cores: P-cores (performance) + E-cores (efficiency); dynamic scheduling, DVFS. SoC integration: CPU + GPU + NPU + DSP + ISP + modem on a single chip Ecosystem: Android, iOS, Linux, macOS, Windows on ARM. What Is a CPU Core?

In multicore CPUs, each core has its own ALU, Control Unit (CU), and registers. The cores share main memory and the system bus. The cores share some of their resources. This allows the CPU to execute multiple instructions simultaneously.

What Is a CPU Thread?

In multithreaded processors, each physical core contains multiple logical processors. Threads share the resources of the core. The operating system treats them as physical processors.

Expansion Cards – ISA Bus

ISA = Industry Standard Architecture

Characteristics: Introduced in 1984 16-bit data bus 8 MHz clock speed Supported cards (main types) Network card Sound card Graphics card Hard disk controller card Successor: EISA (1987)

Expansion Cards – VESA Bus

VESA = Video Electronis Standard Association

Characteristics: Introduced in the early 1990s 32-bit data bus 25–100 MHz clock speed Supported cards (main types) Graphics card Network card Hard disk controller card I/O card

Expansion Cards – PCI Bus

PCI = Periferial Component Interconnect

Characteristics: Introduced in the early 1990s 32–64-bit data bus 33–66 MHz clock speed Plug and Play support for expansion cards Supports almost all types of expansion cards Versions: PCI 1.0, 2.0–2.3, PCI-X, PCI Express

Expansion Cards – AGP Bus

AGP = Accelerated Graphics Port

Characteristics: Introduced in the late 1990s Designed for graphics cards Improved graphics performance Higher speed than PCI Versions: 1x, 2x, 4x, 8x

Expansion Cards – PCI Express Bus

The most common expansion bus in modern computers

Characteristics: Introduced in 2003 Serial bus Four main lane configurations; most devices use x4 or x16 Replaces earlier bus standards Versions: 1.0–6.0, with 7.0 coming soon Graphics cards, SSDs, network cards, sound cards, etc.

BIOS

BIOS = Basic Input/Output System, the interface between the computer’s hardware and software.

Main functions POST (Power On Self Test) Initializing hardware components Selecting the boot device Defining the boot order Loading the operating system CMOS settings Security features Firmware update Handling hardware interrupts

CMOS

CMOS = Complementary Metal-Oxide Semiconductor, a small memory used to store BIOS settings.

Main functions Storing system settings (even when the computer is powered off) Communication with the BIOS Implementation Usually NVRAM (Non-Volatile RAM)

CMOS Setup Utility

A utility for configuring BIOS settings

Some important functions: Basic and advanced settings Hardware information and status Security settings Power management Restoring default (factory) settings

Power Supply Connectors

Provide power to the motherboard, processor, fans, and some peripherals.

Power connector types: AT (older computers, ribbon-style connector) ATX (Advanced Technology Extended), 20/24-pin – motherboard power EPS (Extended Power Supply), 4+4 or 8+8-pin – CPU power PCIe – power for graphics cards and high-power expansion cards SATA 15-pin – primarily powers storage devices Molex (older computers, 4-pin)

Motherboard Cooling

Main motherboard components requiring cooling: CPU → dedicated cooler (fan + heatsink, or liquid cooling). VRM (Voltage Regulator Module) → heatsinks around the CPU to maintain stable power delivery. Chipset → often actively cooled in older systems; usually a passive heatsink today. M.2 SSDs → often use dedicated heatsinks because they can run hot at high speeds.

Cooling solutions: Passive cooling → aluminium heatsinks (chipset, VRM). Active cooling → small fan (older chipsets, high-end motherboards). Additional cooling → liquid-cooling blocks on premium motherboards.

Fan Connectors

Older types Molex (4-pin peripheral connector) Powered directly from the PSU (typically 12 V). No speed control. Now obsolete; used with older case fans.

Modern motherboard connectors 3-pin fan connector (DC) 1: ground, 2: +12 V, 3: tachometer (speed feedback). Controlled by voltage regulation. 4-pin fan connector (PWM) 1: ground, 2: +12 V, 3: tachometer, 4: PWM control signal. More precise speed control and quieter operation. Current standard for CPU and case fans.

HDD – Advantages and Disadvantages

Advantages High capacity (up to 24 TB) Low-cost storage Reliable for long-term storage Multiple interfaces: IDE, SCSI, SATA, SAS Disadvantages Slow (150–300 MB/s) Sensitive to physical shock Moving parts Future Servers and data centres (low cost, high capacity) New technologies, e.g. laser-assisted writing and reading Capacity expected to reach 30–40 TB

Secondary Storage – SSDs

An SSD (Solid State Drive) is an internal storage device based on NAND flash memory.

NAND flash memory Memory cells are arranged in a grid

A memory cell can store one or more bits (SLC – Single-Level Cell, MLC, TLC, QLC) Cells contain one or more floating-gate transistors

The state of the memory cell is determined by the presence or absence of charge on the floating gate.

Typical interfaces: SATA, M.2, U.2, PCIe

SSD – Advantages and Disadvantages

Advantages Significantly faster data transfer than HDDs No moving parts Lower power consumption Compact size, multiple form factors Multiple interfaces/protocols: SATA, PCIe, NVMe, etc. Disadvantages Higher cost Limited write endurance Future Higher speeds (PCIe) and capacities (up to 100 TB), with broader adoption

Data Storage – What to Expect

Emergence of new memory technologies Memristor – fast, durable, non-volatile memory bridging RAM and secondary storage Phase-change memory (PCM) – stores 0 and 1 using phase changes in a material STT-MRAM (Spin-Transfer Torque Magnetic RAM) – magnetic, energy-efficient, durable memory ReRAM (Resistive RAM) – data storage based on changes in electrical resistance

Increasing data density HAMR (Heat-Assisted Magnetic Recording) and MAMR (Microwave-Assisted Magnetic Recording) for HDDs Holographic storage – 3D laser-based storage with theoretical TB–PB capacities

New theoretical directions Quantum data storage – using quantum bits (qubits) DNA data storage – storing data in biological molecules at extremely high density and with long lifespan

Usage trends Growth of cloud storage – supplementing or replacing local physical storage Edge storage – handling data closer to its source (IoT, smart devices)

Monitor Connectors

VGA (Video Graphics Array, D-Sub, analogue) Introduced in 1987; the PC monitor standard for decades. Analogue signal only; practical high-quality limit around Full HD. Now obsolete, but still occasionally found on projectors.

DVI (Digital Visual Interface, digital/analogue) Introduced in 1999 as the digital successor to VGA. Variants: DVI-D (digital), DVI-A (analogue), DVI-I (combined). Max. 1920×1200 (Single Link) or 2560×1600 (Dual Link). Also being phased out.

HDMI (High-Definition Multimedia Interface) Introduced in 2003, primarily for TVs and home entertainment devices. Digital video + audio over a single cable. Still widely used today, including on monitors and laptops. Versions include HDMI 1.4 (Full HD/4K), HDMI 2.0 (4K 60 Hz), HDMI 2.1 (8K, 120 Hz).

DisplayPort (see later) + others (Mini DisplayPort, USB-C, Thunderbolt)

HDMI (High-Definition Multimedia Interface)

Primarily used to transmit audio and video between computers and monitors.

Characteristics: Introduced: 2003 Signal: digital video + audio over one cable + additional data Main uses: TVs, monitors, game consoles, home cinema

Main versions HDMI 1.4 (2009) → 4K @ 30 Hz HDMI 2.0 (2013) → 4K @ 60 Hz HDMI 2.1 (2017) → 8K @ 60 Hz or 4K @ 120 Hz (gaming, VRR, eARC) HDMI 2.2 (2025) → 16K @ 60 Hz, 12K @ 120 Hz, 4K @ 240 Hz; new Ultra96 cable required

Advantages Widely adopted and compatible Standard connector for TVs and consoles

Disadvantages Less flexible than DisplayPort for monitors (fewer displays over one cable) Shorter supported cable lengths at high resolutions

DisplayPort

Primarily used to transmit audio and video between computers and monitors.

Characteristics Supports video signals up to 16K resolution Daisy-chaining displays Sharp, high-contrast image High bandwidth (up to 77 Gb/s) Multiple connector formats (standard, Mini DisplayPort, USB-C)

Multiple versions (1.2, 1.3, 1.4, 2.0) Backward compatible with HDMI, DVI, and VGA via adapters

Jumpers

Jumpers are small plastic caps containing a U-shaped conductor. They connect or disconnect two pins, allowing switching between two fixed hardware settings.

Modern motherboards have few jumpers; typical uses include: CPU configuration (e.g. clock speed, voltage) Chipset configuration (e.g. bus speed) Boot configuration (e.g. boot order) CMOS reset PnP
