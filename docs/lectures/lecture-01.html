Why is knowledge of IT architecture useful?

Writing software is not enough; it must also be operated so that it is available able to operate under load secure quickly recoverable cost-effective

This requires specialized IT operations (Ops) knowledge.

Historical overview

From the beginnings … abacus, slide rule … Mechanical computers (Schickard, Pascal, Babbage) Electromechanical computers (Zuse) Electronic computers  computer generations

Abacus (3rd millennium BC), slide rule (~1620)

Primarily used for addition and subtraction The rods represent place values, while the beads represent digit values

Abacus Simulator (uni-marburg.de)

Slide Rule Simulator Emulator Replica Collection Scales that slide relative to each other In addition to basic arithmetic, it can be used to calculate roots, logarithms, and trigonometric functions Accuracy of 3–4 decimal digits

Schickard’s calculating machine (1623)

Capable of performing the four basic arithmetic operations Mechanical design: 6 pairs of gears (with10 and 1 tooth) Handled carry operations automatically The prototype under construction was destroyed in a fire Two replicas were built much later

Pascal’s adding machine (1643)

Built using clock components Addition and subtraction only Also handled carry operations Pascal built 7 machines

Babbage’s Difference Engine (~1820)

Mechanical computer 15 tonnes 25,000 components Decimal number system Its construction was mainly hindered by technical limitations A working machine based on Babbage’s plans was not completed until 1991 31-digit representation Mathematical (polynomial) tables

Babbage’s Analytical Engine

Programmable using punched cards Designed to store programs (addressable memory) Printer A precursor of modern computers The machine itself was never fully built, but programs were designed for it (Ada Lovelace) Web Analytical Engine Emulator (fourmilab.ch)

Zuse’s computers (Z1, Z2, Z3 …, from ~1941)

Electromechanical computers (relays) More reliable than vacuum-tube computers Binary number system Program–controlled operation (Z3) Stored-program concept? (not published) Zuse Z3 (historicsimulations.com)

Computer generations

Generations are the major stages in computer evolution.

We distinguish 5 generations 6th generation?

First-generation computers (~1945–55)

Vacuum-tube computers Large size and weight Magnetic drum memory Unreliable operation Machine code Expensive

ENIAC (1946)

Electronic Numerical Integrator And Computer Massive hardware 18,000 vacuum tubes 30 tonnes 2.5 m high, 30 m long Operation time on the order of milliseconds Decimal number system Military purposes (ballistic calculations) eniacrun.png (1900×1070) (drexel.edu)

EDVAC (1949)

Electronic Discrete -Variable Automatic Computer John von Neumann also participated in its development General-purpose computer Program stored in memory Binary arithmetic Input via a typewriter-like device Output via a printer

EDVAC - YouTube

Second-generation computers (~1955–65)

Transistors (much smaller and more reliable than vacuum tubes) Produced in larger quantities (e.g. about 17,000 IBM 1400-series systems) Modular design Emergence of the first high-level programming languages (COBOL, Fortran) ~10⁵–10⁶ operations/s Batch processing – less idle time

Third-generation computers (~1965–72)

Integrated circuits (ICs) Smaller size and greater reliability – minicomputers also appeared Operating systems Keyboards and monitors became common Sales in the hundreds of thousands Semiconductor memory

Fourth-generation computers (~1972–)

Microprocessor High level of integration (LSI, VLSI, ULSI) 100 million operations/s Personal computers Graphical user interface Mouse Small size Low cost

Fifth-generation computers (1986–)

Artificial intelligence Speech recognition Natural-language input Learning capability Parallel processing

The development of semiconductors drives progress

“The number of transistors on chips roughly doubles every two years” (Gordon Moore, 1965)

Computer

Computer  Calculator

A computer is a device capable of storing data and sequences of operations (programs) defined by humans and executing them automatically

In a broader sense, the following devices can also be considered computers: Game consoles (Xbox, PlayStation) Embedded systems (mobile phones, smart devices, engine control electronics, GPS, etc.) some IoT* devices

*IoT = Internet of Things

Embedded systems

Special-purpose computers designed to perform a specific task

They do not look like computers from the outside They are usually small, but can also be large (e.g. traffic-light controllers) Their architecture usually includes: Central processing unit Sensors Output/communication interface Actuators (convert signals, e.g. into motion)

IoT – Internet of Things

Devices equipped with computing capability and network connectivity

This also includes “smart” embedded systems.

Characteristics: Utility Intelligence Dynamic nature Heterogeneity Security?

Components of a computer

Three main functional components: processor, memory and I/O unit

The bus system

A set of communication lines connecting the functional components of a computer. Types: Control bus Address bus Data bus

Von Neumann principles

Stored-program concept (data and instructions are stored in the same memory in the same way) Sequential instruction execution A fully electronic machine operating with the binary number system Functional units: separate input/output unit, control and processing unit, and memory General-purpose applicability

The von Neumann architecture problem

The main problem of the architecture is that the processor often has to wait for memory operations, so most of its processing time is unused (“von Neumann bottleneck”)

Other architectures also exist, e.g.: Harvard architecture Parallel architectures

Harvard architecture

Separate data and instruction memory Greater security Better performance More complex design Applications: Microcontrollers CPUs

Parallel architecture

Processing multiple data items and/or instructions simultaneously Higher performance Several models More difficult to program

Parallel architecture – example

UMA – Uniform Memory Access The processors share memory equally Either all processors have equal access to peripherals (symmetric multiprocessing) or only certain processors do (asymmetric multiprocessing)

Aside: quantum computers

They operate based on quantum mechanics Quantum bits (qubits) instead of bits Two key properties Superposition Entanglement Compared with conventional computers, they can be many orders of magnitude faster

Quantum computers

Challenges: Sensitive even to very small disturbances As the number of qubits increases, error detection and correction become increasingly difficult They require new algorithms and software

It may still take 10–30 years before they become widespread

The processor (CPU – Central Processing Unit)

The central processing unit of the computer interprets and executes instructions Components: Control Unit Arithmetic Logic Unit Registers

The Control Unit (CU)

The part of the processor that

Controls data flow between the ALU and the registers Interprets instructions Converts instructions into control signals

The machine instruction cycle

Fetch: read the address of the next instruction from the PC register Decode: decode the instruction stored in the IR Execute: the CPU passes the required information to the ALU, which executes the instruction

Registers

Small, very fast storage locations Typically 8, 16, 32 or 64 bits wide Usually implemented as static storage They can store

Data: AX, BX, CX, DX Memory addresses: SI, DI, SP, BP, CS, DS, SS, ES, IR Status and control

CISC and RISC processors

CISC Complex instruction set
Compound instructions One instruction – multiple clock cycles
One register set Longer execution time

RISC Reduced instruction set
Simple instructions One instruction – one clock cycle
Multiple register sets Shorter execution time

CISC = Complex Instruction Set Computers RISC = Reduced Instruction Set Computers

Main memory

Stores programs currently being executed and the data they require Random access (RAM – Random Access Memory) The processor can access and address it directly Its contents are lost when power is turned off Usually dynamic RAM (DRAM) – requires refreshing

Memory addressing

Main addressing modes (addresses are hexadecimal) Direct memory addressing Segment:offset addressing (segment register + offset) Indirect addressing (the address is stored in a register) Base-relative addressing (base register + offset)

Memory hierarchy

Cache memory bridges the speed gap between components operating at different speeds It has multiple levels; e.g. Level 1 cache between the CPU and main memory

The I/O unit (peripherals)

Input devices (e.g. mouse, keyboard) Output devices (e.g. printer, monitor) I/O devices (e.g. hard disk drive)

Ports

A PORT is a computer interface used to communicate with peripheral devices. It provides a standardized connection between the CPU and peripherals via the system bus (external bus).

Serial and parallel data transmission

When data is transferred between the peripheral interface and the peripheral one bit at a time, sequentially, this is called serial data transmission. (e.g. mouse, modem) When groups of bits are transferred simultaneously between the peripheral interface and the peripheral, this is called parallel data transmission (e.g. printer). USB – high-speed serial transmission

Interrupts

The currently executing activity is suspended The data required to resume execution must be saved The interrupt service routine must be started
